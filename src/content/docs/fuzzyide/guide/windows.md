FuzzyIDE provides several specialized windows to help you manage your workflow directly within the Unity Editor.

## Accessing the Windows

You can open all the tools and panels provided by FuzzyIDE through the top menu in the Unity Editor. Navigate to:

**`Window > Fuzzy Logic Labs > Fuzzy IDE`**

From this menu, you can access various windows, including:

- **Code Editor:** The main IDE window where you can write and edit your C# scripts.
- **AI Assistant:** Opens the AI chat and assistant panel to help you with code generation and debugging.
- **Live Watch Tracker:** A panel for real-time tracking and monitoring of your variables during play mode.
- **Terminal:** Opens the integrated command line interface directly inside Unity.

## Docking and Layout

Since these tools are native Unity Editor windows, you can dock them anywhere in your Unity layout. You can group them together as tabs or place them side-by-side with your Scene and Game views for a seamless development experience.
